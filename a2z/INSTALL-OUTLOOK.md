# How to install your A2Z email signature in Outlook

Open your personal signature link (you will receive it by email), for example:
`https://intuicioerp.github.io/client-signature-icons/a2z/dist/marly-springer.html`

The page shows only your signature. Then:

1. Click anywhere on the page and press **Ctrl + A** (Windows) or **Cmd + A** (Mac) to select everything.
2. Press **Ctrl + C** / **Cmd + C** to copy.
3. Paste it into Outlook as described below for your version.

## New Outlook for Windows / Outlook on the web (outlook.com, Microsoft 365)

1. Click the **gear icon** (Settings) → **Account** → **Signatures**.
2. Click **+ New signature** and give it a name (e.g. "A2Z").
3. Click inside the editor box and press **Ctrl + V** / **Cmd + V**.
4. Under *Select default signatures*, choose it for **New messages** and **Replies/forwards**.
5. Click **Save**.

## Classic Outlook for Windows (desktop)

1. **File** → **Options** → **Mail** → **Signatures…**
2. Click **New**, type a name, then click inside the *Edit signature* box and press **Ctrl + V**.
3. On the right, choose the signature for **New messages** and **Replies/forwards**.
4. Click **OK**.

## Outlook for Mac

1. **Outlook** menu → **Settings** → **Signatures**.
2. Click **+**, name it, click inside the editor and press **Cmd + V**.
3. Set it as default for new messages and replies, then close the window.

## Tips

- Send a test email to yourself and to a Gmail address to check that images and links work.
- If images appear as empty boxes, click **"Download pictures"** / **"Show blocked content"** once; recipients
  who have external images blocked will see the same until they allow them — that is normal for all signatures.
- Do not resize or edit the signature inside Outlook; ask for a new version instead.

## Outlook on your phone (iPhone / Android)

The phone app does not render the full signature: use the text-only version, see [INSTALL-OUTLOOK-MOBILE.md](INSTALL-OUTLOOK-MOBILE.md).
