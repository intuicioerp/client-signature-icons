## En el ordenador (Outlook, Outlook web, Mac)

1. Abre tu enlace personal:
   - <Nombre>: https://intuicioerp.github.io/client-signature-icons/<cliente>/dist/<slug>.html
2. Selecciona todo (**Ctrl + A** / **Cmd + A**) y copia (**Ctrl + C** / **Cmd + C**).
3. En Outlook: **Configuración → Cuenta → Firmas → + Nueva firma**, pega y elígela para mensajes nuevos y respuestas. Guarda.
   (Outlook clásico: **Archivo → Opciones → Correo → Firmas…**; Mac: **Outlook → Configuración → Firmas**.)

## En el móvil (Outlook para iPhone / Android)

Outlook del móvil solo acepta firmas sencillas, así que ahí usamos una versión de solo texto.

1. Copia tu bloque:

```
<Nombre>
<Cargo> | <Cliente>
<email>
<móvil>
<web>
```

2. **iPhone:** Outlook → tu foto o inicial (arriba a la izquierda) → **engranaje** → **Firma**. Si tienes varias cuentas, activa **Firma por cuenta**. Borra "Obtener Outlook para iOS", pega y vuelve atrás.
3. **Android:** Outlook → tu foto o inicial → **engranaje** → **Firma** (elige la cuenta si tienes varias). Borra "Obtener Outlook para Android", pega y toca **✓**.
