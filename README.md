# client-signature-icons

Public images and generated email signatures for clients, one folder per client.

```
<client>/images/    PNG assets (logos, photo, social icons)
<client>/dist/      generated signatures, one HTML file per person
```

| Client | Signatures | Desktop guide | Phone guide |
|---|---|---|---|
| Moving Life | https://intuicioerp.github.io/client-signature-icons/moving-life/dist/index.html | [moving-life/INSTALL-OUTLOOK.md](moving-life/INSTALL-OUTLOOK.md) | [moving-life/INSTALL-OUTLOOK-MOVIL.md](moving-life/INSTALL-OUTLOOK-MOVIL.md) · [mobile signatures](https://intuicioerp.github.io/client-signature-icons/moving-life/dist/movil/index.html) |
| A2Z Move Management | https://intuicioerp.github.io/client-signature-icons/a2z/dist/index.html | [a2z/INSTALL-OUTLOOK.md](a2z/INSTALL-OUTLOOK.md) | [a2z/INSTALL-OUTLOOK-MOBILE.md](a2z/INSTALL-OUTLOOK-MOBILE.md) · [mobile signatures](https://intuicioerp.github.io/client-signature-icons/a2z/dist/mobile/index.html) |

Images are served from `https://intuicioerp.github.io/client-signature-icons/<client>/images/<file>.png`.

## New client

Checklist and delivery email templates (Spanish and English) are in [_template/](_template/README.md).
The delivery email always includes the phone (Outlook mobile) instructions with a text-only signature per person.
