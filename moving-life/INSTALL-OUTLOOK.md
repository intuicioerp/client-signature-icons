# Cómo instalar tu firma de Moving Life en Outlook

Abre el enlace de tu firma personal (te llegará por correo), por ejemplo:
`https://intuicioerp.github.io/client-signature-icons/moving-life/dist/arelys-montilla.html`

La página muestra solo tu firma. Luego:

1. Haz clic en cualquier parte de la página y pulsa **Ctrl + A** (Windows) o **Cmd + A** (Mac) para seleccionar todo.
2. Pulsa **Ctrl + C** / **Cmd + C** para copiar.
3. Pégala en Outlook según tu versión.

## Outlook nuevo para Windows / Outlook en la web (outlook.com, Microsoft 365)

1. Pulsa el **engranaje** (Configuración) → **Cuenta** → **Firmas**.
2. Pulsa **+ Nueva firma** y ponle un nombre (por ejemplo "Moving Life").
3. Haz clic dentro del editor y pulsa **Ctrl + V** / **Cmd + V**.
4. En *Seleccionar firmas predeterminadas*, elígela para **Mensajes nuevos** y **Respuestas/reenvíos**.
5. Pulsa **Guardar**.

## Outlook clásico para Windows (escritorio)

1. **Archivo** → **Opciones** → **Correo** → **Firmas…**
2. Pulsa **Nueva**, escribe un nombre, haz clic en el cuadro *Modificar firma* y pulsa **Ctrl + V**.
3. A la derecha, elígela para **Mensajes nuevos** y **Respuestas/reenvíos**.
4. Pulsa **Aceptar**.

## Outlook para Mac

1. Menú **Outlook** → **Configuración** → **Firmas**.
2. Pulsa **+**, ponle un nombre, haz clic en el editor y pulsa **Cmd + V**.
3. Márcala como predeterminada para mensajes nuevos y respuestas, y cierra la ventana.

## Consejos

- Envíate un correo de prueba a ti mismo y a una cuenta de Gmail para comprobar que las imágenes y los enlaces funcionan.
- Si ves cuadros vacíos en lugar de imágenes, pulsa **"Descargar imágenes"** / **"Mostrar contenido bloqueado"**. Quien reciba tu correo verá lo mismo hasta que permita las imágenes externas; es normal en cualquier firma.
- No cambies el tamaño ni edites la firma dentro de Outlook; pide una versión nueva.
